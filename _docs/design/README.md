# DELTA Design System

The files in this directory (`DESIGN.md`, `tokens.css`, `tokens.json`) are **read-only copies** synced from [`unisdr/delta-design`](https://github.com/unisdr/delta-design) (currently **v0.7.3**, commit `9107103`).

Do not edit these files directly in `PreventionWeb/delta`. Changes to design rules or tokens must be made in `unisdr/delta-design` first and then re-synced here.

[`app/styles/all.css`](../../app/styles/all.css) imports `_docs/design/tokens.css` directly and exposes its semantic tokens to Tailwind CSS v4 via `@theme`.
